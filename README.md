# trimglob

Trim HTML/Markdown glob fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/trimglob/

## Install / run

```bash
git clone https://github.com/theworker02/trimglob.git
cd trimglob
node src/cli.js
node --test
```
